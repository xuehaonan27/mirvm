# M4.1 设计：值与内存 —— 调研报告 + 施工设计

> 状态：**已完成**（2026-07-08，gate1 9/9==native；结果与经验见 m4-log M4.1 条目）。原文如下（历史+机制文档）。原为待审阅（2026-07-07）。按纪律先调研后动手：本文一切判断来自三组真实数据——
> ① 新调研仪器 `--vm-stats`（Trap 债务统计）在 `demo/m4/digest.rs`（M4.1 gate 函数集）上的
> 实测；② `-Zunpretty=mir` 的构造形状 dump；③ 本工具链 rustc 源码的 API 签名 grep。
> 不含凭直觉的排工。

## 0. 调研方法与仪器

新增 **`--vm-stats`**（`src/vm/engine/stats.rs`，纯 IR 分析，永久保留——M4 每期开工前的
标准仪器）：lower 整个程序后聚合全模块 Trap 原因直方图 + 每个 no_mangle 导出的可达 Trap
BFS。**已知盲点**：块因语句失败变 Trap 后，原终止子的 Call 边丢失 → 可达集**低估**
（直方图不受影响）；结果读法是"至少欠这些"。

gate 函数集 `demo/m4/digest.rs`：vec/string/map/box/enum/slice/static/rawptr/float 九个
digest（返回 u64 校验和，无 println——全量差分 M4.3 起，按获批的 gate 修正）。

## 1. 真实债务表（--vm-stats 实测）

**191 个 instance，173 个（90.6%）含 Trap。** TOP 债务（按块计数）：

| 计数 | 债务类 | 归属 |
|---|---|---|
| 108 | 投影 `Deref` | **动态地址**（本期最大头） |
| 20 | BinOp `Offset`（指针算术） | 动态地址 |
| 18 | 终止子 `resume`（cleanup 块尾） | **不阻塞**（见 §2-F1） |
| 18 | 投影 `Downcast`（枚举 variant 字段） | 枚举 |
| 16+11+10+5… | 非标量 place/参数/返回（&str/Option\<usize\>/&[u8]/Layout…） | **ScalarPair/聚合值** |
| 11+若干 | Rvalue `Ref`/`RawPtr`（取址） | 真实地址 |
| 8+6+7 | `__m128i` 相关（hashbrown SSE2 group 探测） | **风险项**（§4） |
| 6+5 | `Transmute`（含 `f64::to_bits`） | 平凡（位搬运） |
| 5 | intrinsic `cold_path` | **intrinsic 政策**（§2-F4） |
| 5+ | `discriminant` 读 | 枚举 |
| 2 | 指针常量（static 引用） | statics 冻结 |

**per-gate 精确欠账**（可达 BFS）：`float_digest` 只差 Transmute；`static_digest` 只差
指针常量+Deref；`box_digest` 7 类；`enum_digest` 7 类（判别式/Downcast/pair place）；
`slice/string/vec` 共通一组（Ref/Deref/Index/胖指针/聚合/迭代器）；`map_digest` 最深
（§4 风险项）。

## 2. 关键发现（每条改变施工判断）

- **F1 `resume` 不阻塞 M4.1**：18 处 resume 全在 cleanup 块尾——正常路径不进 cleanup 块，
  Trap 占位即可。unwind 语义整体归 M4.2（既定），本期零投入。
- **F2 Drop glue 是 M4.1 刚需，且它只是一个 Call**：vec/string/map 出作用域触发
  `Drop` 终止子带真 glue（`box_digest` 实测欠 `Drop glue（ty=Box<u64>）`）。glue instance
  已被收集器收集（DropGlue 有合成 MIR，`instance_mir` 直接给），lower 解析
  `drop_in_place` instance → 普通 `Call`。**unwind 路径才是 M4.2**，正常路径 Drop 本期做。
- **F3 ScalarPair 是本期第二支柱**：`std::alloc::Layout`（{size,align} 两 usize，
  分配链全员按值传）、`Option<usize>`、`&str`/`&[u8]` 胖指针、`(u64,bool)`——非标量债务的
  大头其实都是**双标量**。值模型支持 pair（参数/返回/place/常量）即可解锁分配链与迭代器。
- **F4 intrinsic fallback body 不被收集器自动收**（`cold_path` 实测坐实 D5 的"须核实"）：
  调用点解析成 `InstanceKind::Intrinsic`，其 fallback body **不在** mono 集里。政策落地：
  **引擎内建表**处理高频（cold_path/assume/likely=nop、black_box=copy、transmute 系=位搬运、
  copy_nonoverlapping/write_bytes=memcpy/memset、ptr offset 系=算术）；确需 fallback body 的
  → lower 自行补收（把 Item instance 加入待降低队列，动态扩集）。
- **F5 statics/常量重定位的全部设施现成**（API 已核签名）：
  `tcx.eval_static_initializer(DefId)` → ConstAllocation；`alloc.provenance().ptrs()` →
  `SortedMap<Size, CtfeProvenance>`（重定位表！）；`tcx.global_alloc(id)` →
  `{Memory(ConstAllocation), Static(DefId), Function(Instance), VTable(..)}`；
  **`tcx.vtable_allocation((ty, trait))` 直接给出现成的 vtable 分配**——vtable 不需要自己
  合成，走同一套重定位机器。MIR 实测形态：`_3 = const {alloc1: &[u64; 8]}`（指针常量）、
  `const "m4!"`（`ConstValue::Slice`）。
- **F6 真实地址 ⇒ ByteRegion 必须地址稳定**：`Ref`/`RawPtr` 取的是**帧内局部的真地址**
  （`&arr`、`buf.as_mut_ptr()`），现 ByteRegion 是 `Vec<u8>` 会**搬家**——必须改成
  **mmap 定容区**（GuestMemory 同款），帧地址终身稳定。这正是 frame-abi §2.2 "槽在区里
  是真地址"承诺的兑现点；容量固定 + 到界 = guest 栈溢出近似（frame-abi §9 语义）。
- **F7 Place 不再总能溶解成静态偏移**：`Deref`（108 处）与 `Index` 是运行期地址——M4.0 的
  "(off,width) 静态槽"模型必须升级为**地址表达式**求值（见 §3.1）。

## 3. 施工设计

### 3.1 IR 升级：从"静态槽"到"place 求值"（本期核心改动）

```
Place 求值模型（lower 产出，引擎按序求值）：
  PlaceExpr { base: Local(帧偏移) | Static(冻结真地址) ,
              steps: [ Deref                      // 读出指针值，地址切换为它
                     , Offset(常量字节)            // Field/Downcast 折叠
                     , IndexScaled(idx槽, 步长)    // Index/ConstantIndex
                     ] }
  → 运行期得 (addr: u64)。帧基址是真地址（F6）⇒ 帧内/堆上/statics 全部统一为
    裸地址读写（真实地址模型，§2.5 白赚的根）。
```

- 访问尺寸不再限 ≤8：`Copy { dst_addr表达式, src表达式|常量池, size }`（memcpy 语义）承载
  聚合/pair 整体搬运；标量路径保留 (width) 快路径。
- **ScalarPair 通道**（F3）：参数/返回按两个标量传（引擎调用约定扩为 `&[u64]` 多值 +
  pair 返回走 (lo,hi)）；pair place 的两半按冻结 field 偏移读写。
- 枚举：`Discriminant` 读 / `SetDiscriminant` 写，按冻结 tag 编码（`Variants::Multiple`
  的 direct tag 与 **niche** 两种都要，Option 系全是 niche）；`Downcast` = 偏移折叠（F5 已证
  variant 字段偏移来自 layout.for_variant）。
- 新 Rvalue：`Ref/RawPtr`（= 求 place 地址）、`Aggregate`（逐字段写 + SetDiscriminant）、
  `Transmute`（位搬运）、`PtrToPtr/PointerExposeProvenance/WithExposedProvenance`（真实地址下
  = 位拷贝）、浮点四则/比较（映射宿主 f32/f64，位对位）、`W128`（u128 通道，两槽或 16 字节
  memcpy）。
- 常量：`ConstValue::Slice/Indirect` → **常量池**（lower 期物化字节到冻结内存，重定位后
  取真地址）；指针常量（F5）→ 重定位机器。

### 3.2 statics 冻结与重定位（计划标注的"最复杂单块"，两遍法）

```
遍 1（分配）：从 MonoItem::Static 的根出发，DFS GlobalAlloc 图
   （Static→eval_static_initializer、Memory→ConstAllocation、
     Function→D4 条目表地址、VTable→vtable_allocation 再入 Memory），
   给每个 alloc 在冻结区（mmap，可写：static mut 存在）按 align 分配真地址；环安全（先分后填）。
遍 2（填字节 + 重定位）：拷 init 字节；遍 provenance().ptrs()，在各 offset 写入
   目标 alloc 的真地址 + CtfeProvenance 的 addend。
```

Function 条目表 = D4 的落地起点（本期只需给地址身份；thunk 物化是 M4.4）。

### 3.3 堆（D3 落地）

- 依赖 `libmimalloc-sys`（或 `mimalloc` crate 的底层句柄），薄包装成 `vm/engine/heap.rs`：
  `alloc(size, align) / dealloc / realloc / alloc_zeroed`，真地址直出。
- **拦截点（调研确认）**：`__rust_alloc` 系是 **foreign item**（alloc crate 的 extern），
  lower 在 Call 解析处识别 foreign DefId + 符号名 → 引擎内建 id（os:: 注册表的雏形，P7 起点）。
  `Box::new` 走 `exchange_malloc`（lang item）→ 同表。`libc::malloc` 不拦（既定）。

### 3.4 引擎/加载相分工不变

lower（rustc_private）新增：place 求值编译、枚举 tag 编码冻结、常量池物化、statics 两遍、
foreign→内建路由、intrinsic 内建表 + fallback 补收；engine（纯 Rust）新增：地址表达式求值、
memcpy/标量双路径、pair 调用约定、判别式读写、堆、128 位/浮点算术。纯度门禁（tsan 构建）不变。

## 4. 风险项：HashMap 的 `__m128i`（请决策）

hashbrown 的 group 探测在 x86_64 默认走 **SSE2 路径**（`__m128i` 16 字节向量 +
`_mm_cmpeq_epi8/_mm_movemask_epi8` 系），且在 insert/get 必经路径上（stats 实测 8+6+7 处
相关 Trap；债务普查修复后确认在 map_digest 可达路径，20 处调用实参）。两个选项：

- **A**：M4.1 主线不做 SIMD；`map_digest` gate 改用**自写开放寻址表**（纯 u64 数组，
  同样锻炼堆+聚合+控制流）；`HashMap` 解锁挪到"SIMD 最小集"子项——作 M4.1 尾巴或
  M4.2 顺带，以 stats 复测定量。
- **B**：SIMD 最小集并入 M4.1 主线，gate 保留真 HashMap。

（tier-0 能跑 HashMap 是 InterpCx 路线的能力，对新引擎无移植价值。）

### 4.1 技术评估补充（2026-07-07 调研，回答"是否有硬难点"→ **没有**）

- **存储/ABI 零新增**：16 字节 align-16 值走本期已计划的字节 arena + memcpy 通道 +
  per-local 对齐；解释器调用约定是自己的帧间拷贝，不涉 SysV XMM（那是 M5 JIT 的事，
  且 group 操作永不跨 FFI）。
- **运算 = 4-8 个逐字节 lane 操作**（loadu/store=memcpy、set1 广播、cmpeq、movemask、
  可能 cmpgt/or），每个 ~10 行宿主循环（u128 位技巧或 [u8;16] 循环），**Miri 有全套
  参考实现**（P1）。
- **到达通道两条、汇一张表**：泛型 `simd_*` intrinsic（lane 几何从 layout 的
  SimdVector 读）或 `llvm.x86.*` link_name foreign——都进 D5 内建表 / foreign 注册表
  （第 0/5 步既有机制），零新架构。
- **成本所在**：尾巴长度未知（3-10 个操作，stdarch 实现细节需实测——主线落地后
  `--vm-stats` 复跑即得精确清单）；时序上依赖聚合/memcpy 先就位（最后一公里，非并行块）。
  唯一略繁项：若 set1 走 `simd_shuffle`（const 索引参数 plumbing）。

**修正建议（A/B 合并）：B 的目标、A 的排序**——SIMD 最小集作为施工顺序"第 5.5 步"
（堆/intrinsic 表之后、gate 收口之前），`map_digest` gate 保留真 HashMap；降级条件 =
实测尾巴 >10 个操作时临时换自写 map、SIMD 挪 M4.2。

## 5. Gate 定义（M4.1 完成判据）

`tests/m4_gate1.sh`：digest 九函数（map 按 §4 决策）经 `--vm-call` 全对（期望值 = 同源
native 编译直跑所得，脚本内嵌）；`--vm-stats` 复测：九函数可达 Trap = 0（含 resume 豁免）；
纯度门禁 + spike1-5 + tier-0 diff 16/16 无回归。`rawptr_digest`（栈上裸指针算术 + ptr↔int
往返）= §2.5 真实地址模型的引擎侧实证（内核 mmap 区访问的实证归 M4.3，os:: 后）。

## 6. 施工顺序（增量可验）

0. **worklist 闭包扩集**（全期债务普查的架构级发现，docs/m4-debt-map.md §2-A：collector
   集合是 codegen 视角、跨 crate 非泛型函数不收——先落"种子 + 调用点扩集"，否则 std 非泛型
   函数全是"未收集"）+ **foreign 三路解析骨架**（debt-map §2-B 修订版：①引擎原语表
   （本期 = `__rust_alloc` 系；`__rust_start_panic` 是 M4.2）②guest 导出符号 = 链接仿真
   （`panic_impl` 等 weak lang item → std 实现，查 lang_items/导出符号表）③未知 foreign
   暂 Trap（M4.3 os::）。**panic 前端/fmt 家族照常经 worklist 降低——native 也跑这套代码，
   解释它们是忠实性，不做语义级特判**）
1. ByteRegion → mmap 定容真地址区（F6，一切的地基）
2. place 求值 IR + 引擎（Deref/Index/Offset/Ref——108+20 债务）→ `rawptr_digest`、`slice_digest` 先绿
3. ScalarPair 通道 + Transmute + 浮点/128 → `float_digest`、`enum_digest` 绿（含判别式/Downcast/Aggregate）
4. 常量池 + statics 两遍重定位 → `static_digest`、`string_digest`（&str 常量）绿
5. 堆内建 + Drop-as-Call + intrinsic 内建表（含 atomic_* 直接宿主原子——spike4 义务，不留单线程假实现；`rotate_left` 走 fallback 补收）→ `box_digest`、`vec_digest`、`map_digest`(§4) 绿
6. gate 脚本 + 回归 + m4-log 条目

> per-gate 债务的准确数据（仪器两轮盲点修复后）以 **docs/m4-debt-map.md §4** 为准，
> 本文 §1 的 per-gate 段是修复前的低估版；§4 SIMD 风险经复查**维持**（`__m128i` 实参
> 20 处确认在 map_digest 可达路径）。

## 7. 本期不做

unwind/panic 语义（resume/cleanup 执行、Assert→真 panic）= M4.2；main 启动链/os:: 直通/
getrandom = M4.3；线程/TLS/原子序全映射 = M4.4；`SetDiscriminant` 之外的枚举奇型
（dyn 调用可延后——vtable 冻结本期做，虚调用派发若 gate 未逼出则 M4.2 顺带）。
