# M5.1 设计：轨 A 收口 —— llvm.x86 面清零 + 静态归档装载（待审）

> 状态：**待审阅**（2026-07-12，简报期，应用户要求出稿过目）。
> 前置：M5.0 asm-stub 工厂完成（三面孔清障，tempfile 绿，gate5 31/31）。
> 数据来源：本日实测（逐红用例 --vm-stats 面枚举 + crate 源码 SIMD 后端盘点 +
> llvm.x86 vs simd_* 的 MIR 分流实证）+ grep cg_clif llvm_x86.rs 逐 intrinsic 处置。

## 0. 一句话

M5.0 清掉 inline asm 三面孔后，四个红用例的下一层全落到 `llvm.x86.*`。M5.1 把这层
清零 → corpus 25 项全绿零例外、diff_cargo 3/3，M4 的 asm/intrinsic 脚注彻底删除。
核心手法：**平台 `llvm.x86.*` 硬件 intrinsic → 合成单指令 asm-stub**（复用 M5.0
工厂，扩 xmm/ymm 操作数）——sha256rnds2 这类**强制**走此路（仿真=重写 SHA256，
荒谬且违防静默错值），顺势统一。可移植的 `simd_*` 引擎已覆盖，不重复。

## 1. 调研数据（2026-07-12 实测）

### 1.1 头号发现：面分两个机制（simd_* 已覆盖 / llvm.x86 是真缺口）

`_mm_add_epi32`/`xor`/`cmpeq`/`and`/`or`/`set1`/`loadu` 等在 MIR 层降为 **`simd_*`
rustc intrinsic**（`_mm_add_epi32` → `simd_add`），**引擎 M4.1 起已覆盖**
（`expand_simd`：eq/ne/lt/le/gt/ge/and/or/xor/add/sub/bitmask/reduce/shuffle/splat）。
**只有无可移植等价的**才走 `llvm.x86.*` foreign call（现拦在 `lower/mod.rs:307` →
Trap）：运行期索引 shuffle（pshufb）、SHA-NI（sha256rnds2/msg1/msg2）、movemask、
xgetbv、addcarry。**且带立即数的**（alignr/blend/shuffle_epi32）走 `simd_shuffle`
（const 索引，引擎已支持）——所以 **`llvm.x86` 面全是寄存器-寄存器、无立即数**，
正好避开 M5.0 拒的 const 操作数。

### 1.2 第二发现：--vm-stats 系统性低估面（必须增量发现）

逐红用例 `--vm-stats` 各只报**一个** llvm.x86（numbigint=addcarry.64、blake3=xgetbv、
sha2=ssse3.pshuf.b.128）。原因：特性检测（cpuid/xgetbv）后走 **fn-ptr 间接派发**
选 SIMD 实现，而 vm-stats 可达 BFS 有"fn-ptr 无出边"盲点（AGENT-HANDOFF §8 已记）
——派发之后的 SIMD 内核面看不见。**推论：静态枚举必再低估**（M5.0"修完撞下一层"
的同一陷阱）。故 M5.1 **不承诺"实现这 N 个 intrinsic"，只承诺"corpus 绿"**，结构
= 实现-重跑-再补，直到干。

### 1.3 逐红用例的真实面（源码盘点，非 vm-stats）

| 用例 | 特性检测 | SIMD 内核路径 | M5.1 处置 |
|---|---|---|---|
| **numbigint** | 无 | `addcarry.64`（+ 可能 subborrow）标量进位链 | 引擎 builtin（trivial） |
| **blake3** | xgetbv | **`.S` 静态归档**（build.rs `blake3_sse2_ffi` cfg，Rust 侧 extern "C" 到 `blake3_hash_many_*`；**非 intrinsics**） | xgetbv=asm-stub；内核=D2 归档装载 |
| **sha2** | cpuid（cpufeatures，无 xgetbv） | SHA-NI 路径：**sha256rnds2/msg1/msg2**（llvm.x86，隐式 xmm0）+ pshufb + 大量 `simd_*`（add/xor/shuffle 已覆盖）+ ymm(256 位) | sha256*/pshufb=asm-stub；simd_* 验证补缺 |
| **ecosystem** | xgetbv | memchr SIMD：多为 `simd_*`（cmpeq/and/or/splat 已覆盖）+ movemask/pshufb(llvm.x86) | xgetbv=asm-stub；memchr 面按实测 |

**关键**：blake3 的 SIMD 是**静态归档不是 intrinsic**——它的 intrinsic 面就 xgetbv
一个，主体是 D2。sha2 面最重（SHA-NI 专用指令 + ymm）。

### 1.4 cg_clif 先例（逐 intrinsic 处置核对）

`intrinsics/llvm_x86.rs`：`llvm.x86.sha256rnds2`/`aesni.aesenc` 等无 CLIF 对应的，
cg_clif **本身就用 asm wrapper 兜底**（`InlineAsmTemplatePiece::String("sha256rnds2
xmm1, xmm2")`）——**M5.1 的合成 asm-stub 与 cg_clif 同构**，非独创。sha256rnds2 有
**隐式 xmm0 第三操作数**（cg_clif 注释"Implicit argument"），需特殊处置。

## 2. 决策（请审）

### D7a llvm.x86 拦截分流（`lower/mod.rs:307`）
现 `name.starts_with("llvm.")` → Err。改为 `llvm.x86.*` 查处置表分流：向量硬件 →
合成 asm-stub（D7b）；标量进位 → builtin（D7c）；未登记 → 仍 Err（Trap 诊断，按需
再登记，数据驱动）。非 x86 的 `llvm.*` 维持 Err。

### D7b 向量 llvm.x86 → 合成单指令 asm-stub（复用 M5.0，扩向量操作数）
**为什么是 asm-stub 而非 Rust 仿真**：sha256rnds2/msg1/msg2 的仿真 = 重新实现
SHA256 轮函数，荒谬且违防静默错值（一个字错 = 静默哈希错）。pshufb 的运行期索引
仿真也易错。**真硬件执行 = 精确语义 + "虚拟 CPU=真宿主 CPU"**（用户既定）。既然
sha256* 强制此路，向量面统一走它（无冗余：可移植 op 走 simd_* 不来这）。
- **机制**：处置表 `llvm.x86.NAME → (mnemonic, 操作数形状)`；lower 遇该 foreign call
  合成一个 asm 站点——参数向量按**地址**读入 wrapper 缓冲的 xmm/ymm 槽（`movups
  xmm0,[rbx+off]`，M5.0 wrapper 已含 xmm 分支）、执行指令、结果 xmm 写回返回 place。
  **无立即数**（§1.1），操作数全寄存器类。
- **M5.0 工厂扩展**：`Terminator::InlineAsm` 的 ins/outs 从"标量 8 字节槽"扩到
  "sized 向量槽"（16=xmm / 32=ymm，按地址 memcpy）；interp 执行的 256 字节对齐缓冲
  已够（xmm/ymm 槽）。lower 侧操作数 = `AddrOf(place)` + size（非 scalar 路径）。
- **隐式操作数**（sha256rnds2 的 xmm0）：处置表条目标注，wrapper 生成额外一个固定
  xmm0 输入槽（cg_clif 先例）。
- 【备选：Rust 逐 lane 仿真——sha256* 上不可行（重写 SHA256），pshufb 上易错，弃】

### D7c 标量 llvm.x86 → 引擎 builtin
`addcarry.64`/`subborrow.64`（进位/借位链）= 3 行精确 builtin（`a+b+carry`，
`u128` 检测进位），比 asm-stub（`adc` 需管 CF flag，wrapper prologue 已扰 flag）
**更简更稳**。xgetbv=asm-stub（D7b 一员：真特性寄存器读 `xgetbv`，cpuid 姊妹，
"真宿主 CPU"）。

### D7d simd_* 覆盖验证 + 按缺补
引擎 `expand_simd` 已覆盖主面（§1.1）。sha2/memchr 实测若暴露缺口（如特定 lane 宽
的 add_epi64、simd_shuffle 的边角），按实测补——**不预支未触发的**（M4.5 教训反用）。

### D2 静态原生归档装载（blake3 主体）
lower 收集链接集时补 `tcx.native_libraries(cnum)`（现只收 CLI `-l`，`mod.rs:624`），
对 Static 类（cc 编译的 `.S`/`.c` 归档，如 blake3 的 `libblake3_*.a`）在搜索路径
`lib<name>.a` → `cc -shared -Wl,--whole-archive` 包成 .so（内容哈希缓存，同 M5.0
asm-stub）→ 进 `native_libs` dlopen 清单 → CallForeign dlsym 既有路径命中。真实地址
零编组直调（与 ffi_zlib 无异）。build.rs 产物路径来自 cargo 的 `OUT_DIR`——经
`native_libraries` 的 search paths 拿到。

### D-scope 增量发现（非大爆炸）
§1.2 定：vm-stats 低估 → 每步实现一批、重跑红用例看下一层、再补，直到 corpus 绿。
gate = **用例绿**，不是"实现清单"。每步 commit 带"推进到哪一层"的透明记账（M5.0
复审教训：预期红判据随前沿滚动）。

## 3. 施工顺序（增量，每步一个红用例推进/转绿）

1. **标量解锁**（D7c）：addcarry/subborrow builtin + xgetbv asm-stub（先按标量
   in/out 走 M5.0 现有路径，xgetbv 是 ecx→edx:eax）→ **numbigint 绿**；blake3/
   ecosystem 推进过特性检测到下一层实测。
2. **向量 asm-stub 机制**（D7b 地基）：M5.0 工厂扩向量操作数（16/32 字节槽 I/O）+
   处置表骨架 + pshufb（ssse3.pshuf.b.128）首验 → sha2/ecosystem 推进过 pshufb。
3. **SHA-NI**（D7b 续）：sha256rnds2（隐式 xmm0）/msg1/msg2 处置表 + ymm 槽 →
   **sha2 绿**（差分对拍 native 哈希值）。
4. **D2 归档装载** → **blake3 绿**（差分对拍哈希）。
5. **ecosystem 收口**：memchr 面按实测补（simd_* 缺口 / movemask）→ **ecosystem 绿
   = diff_cargo 3/3**。
6. **gate 滚动 + 收笔**：gate5 预期红清单清空（corpus 25 全绿）；`demo/simd_probe.rs`
   差分探针入 diff.sh（pshufb/sha256/movemask/addcarry vs native，永久上锁，同
   asm_probe）；m5-log M5.1 条目 + handoff/memory。

## 4. 风险与缓解

- **面比预估大（§1.2 低估律）**：增量结构本身是缓解——每步实测下一层，不靠静态
  枚举。sha2 的 ymm(256 位)是已知最重点，槽 I/O 扩到 32 字节即可（M5.0 缓冲 256B 够）。
- **向量操作数 ABI**（llvm.x86 call 的向量参怎么到）：按**地址**读（AddrOf+size
  memcpy），绕开"向量在 xmm 寄存器传"的 ABI 分歧——wrapper 从缓冲 movups 装 xmm，
  与 M5.0 标量槽同构（只是宽 16/32）。首验 pshufb 把关。
- **sha256rnds2 隐式 xmm0**：cg_clif 有先例，处置表条目显式标注；差分对拍 native
  SHA-256 哈希值把关（错一位立现）。
- **D2 归档路径发现**：build.rs 的 `.a` 在 cargo OUT_DIR，靠 `native_libraries` 的
  search paths；若拿不到，退回"cargo 构建时抓 `-L` 路径"（diff_cargo 已有 cargo 壳）。
- **防静默错值**：向量 intrinsic 全程差分对拍真 native（哈希/正则输出逐字节）；
  未登记 intrinsic 响亮 Trap 非静默。

## 5. 不做（本期）

方法级 JIT（M5.2；本期仍解释器，asm-stub 是解释器可直调的机器码）、非 x86 SIMD、
带立即数 asm 操作数（llvm.x86 面无，§1.1）、AES/其他未被红用例触发的 llvm.x86
（数据驱动，触发再登记）、mode B。

## 6. 退出判据（gate = 滚动后的 gate5）

① corpus 25 项**全绿零例外**（blake3/sha2/numbigint 从预期红清单删除）；
② diff_cargo **3/3**（ecosystem 绿）；
③ diff.sh 加 `simd_probe` 差分（pshufb/sha256/movemask/addcarry vs native 逐字节）；
④ 全量回归无损（diff/gate0-4/spikes/TSan/纯度/性能上限）；
⑤ m5-log M5.1 条目（含面的最终实测清单 + 教训）+ handoff/memory 收笔。
