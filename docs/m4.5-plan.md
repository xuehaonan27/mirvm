## 2. 决策（请审）

### D1 corpus 目标 = "全绿 − asm 三项"
blake3/sha2/tempfile 记预期红（M5 JIT asm 块，既有决策不动），其余 5 类债全清。

### D2 性能硬门重述（原文对象已消失）
原硬门"不慢于 tier-0"失去对象——tier-0 已删，留存可比数字仅 rayon（28s→0.9s，
30×，硬门在该点已远超）。重述为：
- **绝对上限进 gate5**：加载相（空程序）≤ 1s；rayon ≤ 5s；corpus 单用例 ≤ 60s。
- **记录加速比**（m4-plan 原要求）：rayon 30× 记入 m4-log。
- **fib(32) ~120× vs native 记为 M5 JIT 的基线锚点**，不设硬门（解释器档位是
  已知取向，JIT 的份内）。

### D3 进程生成：posix_spawn* 移出 denylist（推荐）
posix_spawn 的 fork 子体**立即 exec**——VM 状态从不在子进程里运行，与裸 fork
直通（子进程带着完整 VM 镜像着陆）风险完全不同；file_actions/attr 是不透明结构体
指针，真实地址模型下直传天然成立。裸 fork/vfork/clone/exec 前缀维持 denylist
（atfork 挂起项不动）。解锁 std::process::Command（c_process）。
【备选 B：维持 denylist，c_process 记 M4 后——不推荐，Command 是生态高频面】

### D4 async 收口定义
= tokio（单线程）+ c_tokio_mt 跑通（D1 的 Adt 胖化是前置；epoll/net 直通已绿，
async_hand/async_suspend 已在 diff 16/16）。修完 #1 后若 tokio 暴露下一层债，
按实测再清（施工顺序把它放第 1 步就是为了早暴露）。

### D5 "切默认"重述为 M4 关账
原义"--engine 默认切 vm"已在 tier-0 移除时发生。本期收笔动作 = m4-plan 总验收
四条逐条对勾（语义/并发/架构/性能）+ m4-log M4.5 条目 + 挂起项移交清单
（M5：JIT/asm 块/vmctx P-R 终裁/LSDA；mode B：预降 std 工件）+ handoff/memory 收笔。

### D6 .init_array：按需挂起（本期不做）
tier-0 有扫描先例（for_each_linked_def 注释），但当前无任何用例逼它——
ctor 类 crate 进 corpus 时再落，不预支。

## 3. 施工顺序（每步可验）

1. **Adt 递归胖化**（cg_ssa coerce_unsized_into 同构：同 def 字段递归到指针对，
   meta 复用 M4.4 struct_lockstep_tails 逻辑）→ 最小重现 + clap 绿，tokio/tokio_mt
   跑到下一层实测
2. **intrinsic 三件**：raw_eq / log 族 / size_of_val+align_of_val-unsized
   → csv/numbigint/walkdir 绿
3. **128 位判别式 tag**（先 dump ecosystem 实际 MIR 定形状；Direct 优先，Niche
   128 位若不可达不预支）→ ecosystem 绿 = diff_cargo 3/3
4. **posix_spawn 直通**（若 D3 批 A）→ c_process 绿（差分验证子进程 IO）
5. **tests/m4_gate5.sh**：corpus 全量（asm 三项预期红注记）+ diff_cargo 3/3 +
   D2 性能上限表 + 全量回归（gate0-4/diff/spikes/TSan/纯度）
6. **M4 关账**（D5）：m4-log 条目 + 总验收对勾 + 移交清单 + 文档/memory 收笔

## 4. 风险与缓解

- **tokio 的下一层未知**：waker/park/timer 路径未测——第 1 步先行早暴露；
  net/epoll/线程/TLS 地基全绿，剩余面预期是点状 intrinsic/cast。
- **128 位 tag 牵 TagInfo 全链**：SwitchInt/Discriminant/SetDiscriminant 三处
  都吃 tag_w——dump 定形状后再动，Direct-only 若够就不碰 Niche。
- **posix_spawn 的参数面**：pid 出参/file_actions 指针直传即真地址；风险在
  信号相关 attr 与 stub-A 的交互——c_process 差分把关。

## 5. 不做（本期）

inline asm（M5）、.init_array（按需，D6）、weak fn 符号真地址化（按需）、
fork/atfork（挂起项）、性能优化本身（M5 JIT；本期只固化基线与上限）、mode B。

## 6. 退出判据

corpus = 全绿 − asm 三项预期红（含 c_process/c_tokio_mt）；diff_cargo 3/3；
diff.sh 16/16 + gate0/1/2/4 无损 + TSan 零警告；gate5 含性能上限表并记录加速比；
m4-plan 总验收四条对勾；m4-log/handoff/memory 收笔。
