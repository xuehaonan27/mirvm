## 1. 调研数据（2026-07-13 实测）

### 1.1 探针结果（native vs mirvm 差分，14 项）

| 探针 | native | mirvm | 判定 |
|---|---|---|---|
| **`f64::abs()`** | 过 | **TRAP `fabs` 无 fallback**（本 nightly `fabs` 改泛型名，mirvm 剥后缀匹配 miss——最高频浮点函数是暗洞，corpus 恰好无人调） | **漂移硬伤** |
| 深递归 50k 帧 | 过 | **TRAP 深度>8000**（`interp.rs` `MAX_DEPTH=8_000`） | **保真硬伤** |
| `std::simd` 基本算术 | 过 | **TRAP `simd_mul`** 一上来即死 | **大面缺口** |
| `fetch_max/fetch_min` | 过 | **TRAP `atomic_max` 无 fallback** | 缺口 |
| `mul_add`（fma） | 过 | **TRAP `fmaf64` 无 fallback** | 缺口 |
| f16/f128 算术 | 过 | **TRAP 浮点宽度 f16** | 缺口 |
| `Command::pre_exec` | 过 | **TRAP foreign `fork` denylist**（std `do_fork`） | 缺口 |
| `global_asm!` 定义符号 | 过 | **dlsym 全域未命中**（符号未物化） | 缺口 |
| naked fn | 过 | TRAP `naked_asm!（M5.x）` | 缺口（已预标） |
| `libc::atexit` guest 回调 | 过 | **dlsym 未命中**（glibc 不导出 `atexit`，须 `__cxa_atexit`/builtin） | 缺口 |
| `#[global_allocator]` 计数 | 3 次分配 | 1 次（guest 实现**有**被调到，但计数不一致） | **待查** |
| 自定义 DST（slice 尾/dyn 尾单层） | 过 | 过；仅**嵌套** DST 尾 TRAP（M4.6+ 已预标） | 窄缺口 |
| gen 块 / panic hook | 过 | 过 | 无缺口 |
| 具名浮点数学（sqrt/sin/pow/ln/exp2/log10/copysign/floor/round，f32/f64） | 过 | 过 | 无缺口 |

### 1.2 intrinsic 权威差集（rustc 源码为准，非凭记忆）

- **simd 家族：全集 75，已覆盖 20，缺 55**。已覆盖：add/sub/and/or/xor/shl/shr、六比较、
  bitmask/reduce_all/reduce_any、shuffle/splat/insert/extract。缺口按类：
  - 算术：`mul div rem neg saturating_add saturating_sub funnel_shl funnel_shr arith_offset`
  - 浮点：`fabs fsqrt fma relaxed_fma ceil floor round round_ties_even trunc
    maximum_number_nsz minimum_number_nsz` + StdFloat 超越族 `fsin fcos fexp fexp2 flog flog2 flog10`
  - 位：`bswap bitreverse ctlz cttz ctpop`
  - 转换/指针：`cast as cast_ptr expose_provenance with_exposed_provenance`
  - 访存：`gather scatter masked_load masked_store`
  - 选择/归约：`select select_bitmask`、`reduce_{add,mul}_{ordered,unordered} reduce_{and,or,xor,max,min}`
  - 动态 lane：`extract_dyn insert_dyn`；另有 `carryless_mul`（clmul，stdarch 面）
- **非 simd 差集（按 rustc 权威规则三分类：`must_be_overridden = !has_body`）**。
  **真缺口（无 fallback、运行期可达、无处理臂）**：
  - `fabs`（**漂移**：本 nightly 改泛型名无后缀，探针实证 `.abs()` 即 Trap；引擎
    `M::Fabs` 分支现为死代码）；
  - `atomic_max / atomic_min / atomic_umax / atomic_umin`（RMW 臂缺四个，探针实证）；
  - `fma{f16,f32,f64,f128}` + `fmuladd{f16,f32,f64,f128}`（探针实证 `mul_add` Trap）；
  - f16/f128 具名数学 32 个（`{sqrt,sin,cos,exp,exp2,log,log2,log10,floor,ceil,trunc,
    round,round_ties_even,pow,powi,copysign}` × f16/f128）——归 D8c 随类型一并落地；
  - fast/algebraic 浮点 10 个（`f{add,sub,mul,div,rem}_{fast,algebraic}`）——按精确
    语义执行即合规（fast-math 是自由授权，精确结果在允许集合内）；
  - `volatile_copy_memory / volatile_copy_nonoverlapping_memory / volatile_set_memory /
    nontemporal_store`（引擎仅有 volatile load/store）；
  - 杂项：`ptr_mask / vtable_size / vtable_align / breakpoint`。
  **保险臂**（正常被 GVN/常量折叠消解，残留即 Trap——lower 期用 tcx 补 const 折叠臂）：
  `size_of / align_of / type_id / type_name / variant_count / offset_of / needs_drop /
  field_offset`。
  **非缺口（已核实）**：`LowerIntrinsics` MIR pass 提前消解 `unreachable/forget/
  wrapping_*/unchecked_*/·_with_overflow/read_via_copy/write_via_move/discriminant_value/
  aggregate_raw_ptr/ptr_metadata/transmute_unchecked/three_way_compare(→BinOp::Cmp)/
  const_eval_select(重映射直调)`；`rotate_left/right、select_unpredictable、va_copy/va_end、
  minimum/maximum 族`等 51 个有 fallback body（引擎直接解释）。`va_arg/autodiff/
  rustc_peek/SVE 5 个`归 D8l 不做。
- **atomic 序参数被整体丢弃**（agent 核出）：本 nightly atomic intrinsic 顺序改
  const 泛型 `ORD`，引擎完全不读、一律按宿主 SeqCst 执行。强化序**合规**（SeqCst 执行
  ⊂ 弱序允许集合），但违背 concurrency-arch"弱内存序自然恢复"的既有承诺、x86 上
  Relaxed store 也吃 xchg 代价、且 TSan 语境失真——归 D8j 贯通。
- **教训延续**（M5.0/5.1"修完撞下一层"）：vm-stats 有 fn-ptr 盲点，静态枚举必低估；
  本期仍**不承诺"实现这 N 个"，只承诺探针/用例绿**，结构 = 实现-重跑-再补。

### 1.3 拒绝面清点要点（全量清单已存档，实现时按行号索引）

- **OS/进程**：`DENY_EXACT`＝fork/vfork/clone/clone3/setjmp/longjmp/sigsetjmp/siglongjmp/
  pthread_exit/pthread_atfork；`DENY_PREFIX`＝`exec*`（`lower/mod.rs:48-60`）。
- **signal**：guest handler 显式 Trap（`interp.rs:1636,1646`）；SIG_DFL/IGN 直通。
- **unwind/backtrace**：`_Unwind_*` 16 符号整组 `Builtin::Unsupported`（`lower/mod.rs:581-600`）。
- **FFI**：按值聚合拒（`非标量（按值聚合）`）、变参回调拒、ZST cif 参数拒。
- **asm**：naked/may_unwind/noreturn/att_syntax/const/sym/label（asm goto）拒（`func.rs:2208-2258`）。
- **128 位残余**：个别 BinOp 形态、tag 宽>8B、128 位常量 cast、`Transmute pair→聚合`、
  `InvalidEnumConstruction`（u128 实参）。
- **DST**：嵌套 DST 尾字段动态对齐（`func.rs:248`，单层 slice/dyn 尾已通，探针证实）。
- **栈**：解释帧深度 8_000 上限 + 操作数区 MiB 上限两道守卫（`interp.rs:1251`、`engine/frame.rs:55`）。

## 2. 决策（请审，D8 系列）

### D8a 栈深度保真（探针第 1 硬伤）
执行相迁到**专用大栈线程**：主 guest 执行不再borrow rustc 驱动线程的 ~16MB 栈，
mirvm 自建执行线程（默认 reserve 1 GiB 虚拟栈，Linux 下按需 commit，零实际内存代价），
深度上限从硬编码 8_000 改为**按实测每帧宿主成本标定**（`栈字节 ÷ 标定值`，保守系数），
配 `--stack-size` 旋钮（JVM `-Xss` 同位）。guest `thread::Builder::stack_size` 同样乘
放大系数（guest 按 native 帧尺寸要求栈，解释帧放大 ~数十倍）。到界诊断保留（语义 =
native "has overflowed its stack" 同构，可观测行为对齐）。操作数区上限同步随栈标定。

### D8b simd 55 缺口全补（探针第 2 硬伤）
主路 = 现有 `expand_simd` 的 **lane-wise 展开**（mul/div/rem/neg/位族/转换/选择/归约/
saturating/funnel 均为纯标量循环，机械量大风险低）；`gather/scatter/masked_*` 需
**逐 lane 条件访存**新形态（mask lane 控制读写，佯读/佯写禁止——防越界）；StdFloat
超越族（fsin/fcos/fexp/flog…）**逐 lane 调宿主 libm**——native 对这些正是 lane 化
libm 调用（LLVM 无 fast-math 时 scalarize 到同一 libm），同源即位同。`fsqrt/fma/round
族`用宿主对应标量指令语义（`f64::sqrt`/`mul_add`——正确舍入有保证）。`extract_dyn/
insert_dyn` 运行期索引界内检查后位拷。`carryless_mul` 挂 D8l 裁决（stdarch clmul 面，
可走 M5.1 的 stdarch helper 通道）。**每类配差分探针**，portable_simd 探针进 corpus。

### D8c f16/f128：libgcc FFI 同源路线
f128 算术/比较/转换 → dlsym `libgcc_s` 的 `__addtf3/__divtf3/__eqtf2/__fixtfdi/
__extendhftf2…`（已核实全量导出）——**与 native codegen 调用同一批符号，位级同源**；
f16 算术 = promote f32 运算再 `__truncsfhf2` 回（native 同款下降，基本运算正确舍入
有数学保证）。存储宽度补 2/16 字节标量通道；`float_to_int_unchecked`/FloatToFloat
等 cast 家族同步补。备选 rustc_apfloat（const-eval 同款）弃：多一套实现、与 native
运行时路径不同源。

### D8d signal 窄化：异步信号直执行（XFAIL c_signal → 绿）
- **异步信号**（SIGINT/SIGUSR*/SIGTERM/alarm 等）guest handler：**AS-trampoline 直执行**
  ——M4.4 thunk 工厂已能物化 guest fn 真机器码入口 + 边界 TLS attach，信号入口复用；
  handler 运行到完成才返回（POSIX run-to-completion），解释帧操作数区是 per-Ctx bump
  LIFO，天然可重入。`signal`/`sigaction` builtin 从"guest handler 即 Trap"改为登记
  guest handler → 装真 trampoline。
- **同步故障信号**（SEGV/BUS/FPE/ILL）guest handler：**维持响亮拒绝**（宿主故障与 guest
  故障不可分辨，伪造恢复=静默错值）。`sigaltstack` 维持拒绝（guest 按 native 帧尺寸给
  的备用栈装不下解释帧）。
- **诚实边界**：引擎在 handler 内的自身机器（如 handler 里 guest 调 malloc）AS-safety
  与 native 等同由 POSIX 约束 guest；引擎自有路径施工时以探针 + TSan 验证重入，
  trampoline 入口保持零分配。设"信号并发投递/嵌套"探针。

### D8e backtrace 影子帧（XFAIL c_backtrace → 绿）
Ctx 维护**影子帧栈**（fn-id + 递归深度，enter/exit 同步）；`_Unwind_Backtrace/
_Unwind_GetIP(Info)/_Unwind_FindEnclosingFunction` 从 `Unsupported` 改 builtin：回调
逐影子帧，**IP = 冻结 fn 条目地址**（进程内唯一、非可执行，作 opaque token 恰好）。
符号化路径（`dl_iterate_phdr`/dladdr 找不到匿名冻结区）诚实产出 `<unknown>` 帧——
backtrace 文本本非 well-defined 可观测（ram-spec §2），**oracle 用不变式**（帧数下界、
捕获成功、panic 链不崩），不逐字节对拍。禁止伪造宿主符号的原则不变。后续（非本期）
可选：物化符号 ELF 让 dladdr 报真 guest fn 名。其余 `_Unwind_Get/Set*` 按"影子帧能
诚实回答的答、答不了的保持响亮"逐个裁决。

### D8f fork 窄化 + exec 直通
- **fork**：guest 线程数==1 时放行（引擎有线程注册表可查；子进程=全进程拷贝，解释器
  状态天然一致；单线程下无锁死锁面）；多线程 fork 维持响亮拒绝（native 下也是雷区）。
  解锁 `Command::pre_exec`（std `do_fork` 路径）与单线程 daemonize 惯用法。
  `pthread_atfork` 维持拒绝。
- **exec 族**：从 DENY_PREFIX 放行为**直通**——exec 语义=整进程替换，VM 状态消失
  本就正确（native 同样不跑 atexit）。fork+exec 窗口内子进程只允许 AS-safe 直通调用，
  违例=guest 自身 POSIX 义务（与 native 等同）。
- vfork/clone/clone3/setjmp/longjmp 家族维持拒绝（§D8l）。

### D8g atexit 家族 builtin
glibc 不导出 `atexit`（探针实证 dlsym 未命中）→ builtin：引擎自持 LIFO 注册表，
首次注册时经真 `__cxa_atexit`（已核实导出）挂**一个** native trampoline，进程收尾
按 LIFO 解释执行 guest 回调（Shared 进程期存活已保证）。`__cxa_atexit`/`on_exit`
同族同实现。探针：注册顺序 + `process::exit` 触发 + main 正常返回触发。

### D8h global_asm! / naked fn（M5.0 工厂扩展）
- `global_asm!`：收集 `MonoItem::GlobalAsm` → 模块级 `.s`（保留符号导出）→ cc 汇编
  `.so` → dlopen 进程解析序（在全域 dlsym **前**查询，asm 符号优先命中）——cg_clif
  `global_asm.rs` 同构（外部汇编器路线一致）。
- naked fn：函数体即单条 `naked_asm!` → 按 global_asm 同路物化为真符号，调用点按
  冻结 extern 签名走 foreign 直调（naked 无序言/结语，本就是裸机器码函数）。
- asm 操作数补面：`const` 操作数（编译期常量格式化进模板——生态常用）、`sym` 操作数
  （fn 条目地址/静态地址重定位进 wrapper，guest fn 用 thunk 机器码地址）。
  `att_syntax` 前缀透传（`.att_syntax prefix` 头 + 恢复）。may_unwind/label 维持拒绝。

### D8i 标量 intrinsic 差集清零（§1.2 真缺口逐项）
`fabs` 匹配修复（泛型名直配，死代码分支复活并加"漂移再犯"回归——**这是'剥后缀匹配'
模式对 nightly 漂移脆弱的实证，同模式的 math 表全体加泛型名兜底**）；
`atomic_{max,min,umax,umin}`（RMW 臂 +4，探针含符号/无符号边界）；`fma/fmuladd` 8 个
（宿主 `mul_add`，正确舍入同源）；fast/algebraic 10 个（按精确语义执行）；
`volatile_copy*/volatile_set/nontemporal_store`（现有 volatile IR 通道扩批量形态）；
`ptr_mask/vtable_size/vtable_align/breakpoint`；nullary 类型查询保险臂（lower 期 tcx
const 折叠，防低优化 MIR 残留）。

### D8j atomic 序贯通
IR 的 `AtomicLoad/AtomicStore/AtomicCxchg/AtomicRmw` 语句补 order 字段（cxchg 补
succ/fail 双序），lower 读 const 泛型 `ORD` 贯通，引擎按宿主对应序执行（Relaxed→
`Ordering::Relaxed` 等映射，x86 上 Relaxed store 回到 plain mov）。现状全折 SeqCst
虽合规（强化序=允许集合子集），但违 concurrency-arch"弱序自然恢复"承诺且 TSan 语境
失真。TSan gate 是本片的安全网（弱序错映射=真数据竞争会被抓）。

### D8k 边角批（逐项小，合一分片）
128 位残余（BinOp 缺口形态、tag>8B、128 位常量 cast、Transmute pair→聚合、
InvalidEnumConstruction u128）；FFI 按值聚合（libffi 原生支持 struct，`FfiKind` 扩
聚合形态，thunk 侧同步）；嵌套 DST 尾动态对齐（M4.6+ 预标项，vtable/meta 递归取对齐）；
`#[global_allocator]` 计数差根因调查（3 vs 1，guest 实现有被调但有分配漏计——查引擎
代跳分配点；`__rust_alloc_error_handler` 顺带注册）；`dl_iterate_phdr` 等旧 StubZero
转直通项的差分探针补课（current-status 遗留）。

### D8l 本期明确不做（登记不失踪）
setjmp/longjmp（非局部控制流穿解释帧=帧模型级工程，生态占比低）；同步故障信号 guest
handler；pthread_exit/pthread_atfork/vfork/clone 直用；`va_arg`（guest 侧 C 变参**定义**，
nightly 特性罕用）；`carryless_mul` 若无真实用例则 Trap 保留；`autodiff/rustc_peek`
（实验/调试 intrinsic）；SVE 5 个（ARM 无关）；checked 模式、`.mirvm` 分发、daemon/REPL
（产品面另期）；非 x86_64。全部保持**响亮 Trap + 原因锁定**，不静默。

## 3. 施工顺序（每片：实现 → 探针/用例 → 全量 gate 绿 → 独立 commit）

1. **标量 intrinsic 差集**（D8i）：fabs 修复打头（最高频暗洞）+ atomic_max 族 + fma 族
   + fast-math/volatile mem/杂项/保险臂 → 探针同 commit 进 diff。
2. **栈深度**（D8a）：执行线程 + 标定 + 旋钮 → `c_recursion` 用例（50k 深）+ 探针进 diff。
3. **simd 补全**（D8b）：先算术/位/转换/选择/归约 lane-wise 一批 → 再 gather/scatter/
   masked → 再 StdFloat 超越族 → `c_portable_simd` 用例 + 分类探针。
4. **atomic 序贯通**（D8j）：IR order 字段 + lower 贯通 + TSan 复跑。
5. **f16/f128**（D8c）：libgcc FFI + cast 家族 → 探针（含 f16 全算术 × 边界值）。
6. **atexit + global_asm/naked + asm 操作数**（D8g/D8h）：工厂扩展一批 → 探针。
7. **backtrace 影子帧**（D8e）：`c_backtrace` XFAIL → 绿（不变式 oracle，gate 判据滚动）。
8. **signal 异步窄化**（D8d）：`c_signal` XFAIL → 绿（handler 真执行断言已在）+ 并发投递探针。
9. **fork/exec 窄化**（D8f）：pre_exec/单线程 fork/exec 直通 → `c_fork_exec` 用例。
10. **边角批 + 收口**（D8k）：128 位残余/FFI 聚合/嵌套 DST/global_allocator 调查/
    dl_iterate_phdr 探针 → gate 判据滚动（XFAIL 清单收缩记账）→ m5-log/current-status/
    decision-history 同步。

**基建纪律**（根 AGENTS.md）：本期**零新增 harness 机制**——只加 corpus 用例、demo 差分
探针与 diff.sh 条目（全部既有通道）；真实项目工作集仅复跑防回归，不扩 workload。

## 6. 风险

- **signal 重入**（最尖）：trampoline 入口零分配 + LIFO 帧域天然可重入是设计论证，
  施工时必须探针实证（信号打断解释器中段 + handler 内再 panic/alloc 的行为矩阵）。
- **fork 后引擎锁**：单线程放行已消掉主死锁面，但 mimalloc/dlopen 内部锁在"其他**宿主**
  线程"（无——单 guest 线程时引擎无后台线程；若未来加后台线程须重审此裁决）。
- **simd 量大**：55 个纯机械但一个 lane 语义错=静默错值——每类探针必须覆盖有符号/
  无符号 × 边界值（饱和、移位越界 lane、NaN 传播、-0.0）。
- **性能**：simd lane-wise 展开在解释器成本可接受（本就慢），JIT 期再向量化；rayon
  硬门看住整体不回退。
